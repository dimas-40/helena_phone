0. 새로 찾은 것 — 배포 구조가 “전체 공개”다

dtslib-cloud-appstore/.github/workflows/deploy.yml:

- uses: JamesIves/github-pages-deploy-action@v4
  with:
    branch: gh-pages
    folder: .          # ← 레포 루트 전체를 그대로 공개 배포

“이 파일만 공개” 스위치가 없다. 레포 = 공개가 기본값. gitignore된 것만 빠진다.

경로 공개 상태
DEVLOG_20260921.md / WHITEPAPER.md / CLAUDE.md 200
mcp/mcp-registry/index.json (개인경로 40건) 200 · 23,776B
id_ed25519 404 ✅ (gitignore 등록, 커밋 이력 0회 — 위생 양호)

→ index.json 40건은 레지스트리 파일 하나의 문제가 아니다. 디렉터리 리스팅은 막혀 있지만
경로를 알면 파일은 그대로 받아진다. 배포 정의(folder: .)를 바꿔야 닫힌다.

1. 정리된 아이디어 12개

# 명제 상태
1 MCP = 생각의 서식. 산출물로 나오려면 실행환경(컨테이너)이 필요 ✅
2 PC 없다는 가정 — 상시설치 대신 GitHub 것을 빌림 ✅ 구현체 있음
3 레포 하나를 여러 디바이스가 공유 ✅
4 투트랙 — 나(ADB 연결): 다운로드 불필요 / 남: 받아가야 함 ✅
5 다운로드의 소멸 — APK 무의미, curl 한 줄이 인스톨러 ✅ 업계 표준
6 설치 주체가 사람이 아니라 에이전트 = 새 배포 플랫폼 ✅ 최고 통찰
7 private 유지 + PIN — Pro 4000원 유지 이유 ✅
8 장부 이원화 — 소스도 “공개 상태”를 갖는 콘텐츠 ⚠️ 파일단위 스위치 불가
9 무거운 건 컨테이너로 ✅ 실물 16GB
10 폰도 워크센터 ⚠️ 배치만 실증
11 백업 플랜 — 한도 내 클라우드 → 넘으면 폰 ✅
12 이름 유지 — 좌판+통제점+구름 ✅

2. 레포가 어떻게 바뀌나

지금: 카탈로그가 둘인데 서로 안 맞는다

apps.json                    22개  ← 랜딩페이지가 그리는 것
                               └ install.command 있는 것 = 3개뿐
mcp/mcp-registry/index.json  34개  ← 기계용 (MCP 실물)

“34개 MCP”와 “22개 앱”이 같은 목록이 아니다. 페이지가 어느 쪽을 말하는지 불분명한 게
구조 전환이 막힌 진짜 원인.

바뀐 후: MCP 3분류가 페이지 뼈대

부류 무게 배포 방식 근거
① 순수 로직 수십 KB 코드 통일 → curl 한 줄 universal 17
② 브라우저/모델 의존 중 컨테이너/의존성 분기 heavy_portable 5
③ 컨테이너 확정 2~16 GB GHCR 주소 50자 container_verified 7
  • 배포처: Vercel ✂(404 확인 완료) → GitHub Pages 단독
  • 통제점: private + PIN
  • 페이지 성격: “설치 안내” → “주문서/트리거 목록”

⚠️ 레지스트리 workcenter:[laptop,minipc,phone] 30개는 낙관치 —
폰은 배치 트리거만 실증, 상주 실행은 미구현.

3. 뭐가 맞았고 뭐가 틀렸나

① AI 오판 7건 — 전부 “방향 과소평가”

AI의 오판 실제 교정
“폰=docker 없음 → 컨테이너 불가” 트리거≠실행. 09-19 3회 실증 Boss
“버셀 유령 미러 1개” 9개였다 Boss
“호출”→”트리거”로 정정 Boss의 “호출”이 이미 정확 Boss
폰이 뷰어일 뿐 폰에서 독립 프로세스가 커밋까지 함 Boss
“컨테이너 2개”=cell/+cell/native/ rvc-trainer+po-deepfake-cell AI 자정정
“월 3,000분 무료” 실측 1,830~7,199분 전부 $0 AI 실측
“PC Chrome 열어라” (폰인데) “내가 핸드폰이잖아” Boss

7건 중 5건을 Boss가 잡았다. 그리고 7건 전부 같은 방향 — AI가 “안 된다”고 과소평가.

② Boss가 정정된 것 4건

Boss 발화 정정
“에이전트가 설치를 대신한다” 업계 표준(curl \| bash) — 새로울 것 없음
“파일 단위 공개/비공개 스위치” GitHub Pages는 레포/폴더 단위
“ADB가 MCP 호출 통로” ADB는 화면·입력 조작 통로
“공짜는 무한이 아니다” Boss가 먼저 정확히 짚음

4. 남은 것 — 우선순위

순위 항목 상태
1 index.json 40건 + folder: . 전체공개 ❌ 살아있음
2 /root/papyrus PAT 평문 (계정 dimas-40) ❌ 미폐기
3 랜딩페이지 구조 전환 ⏳ 랩탑 287031a까지
4 34개 중 3개만 curl 가능 ❌ 진짜 병목
5 폰 → 상주 MCP 브릿지 ❌ 미구현
6 workcenter: phone 30개 ⚠️ 낙관
7 rvc-trainer 매뉴얼 ❌ 아직 “수동”

한 줄: 개념 12개는 정합, 레포는 “카탈로그+설치안내” → “3분류 주문서”로 전환,
AI 오판 7건은 전부 과소평가였고, 실제로 열려 있는 건 1번·2번 두 개뿐.
