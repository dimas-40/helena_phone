## 1. 뭘 만든 거냐

**폰을 켜두면 알아서 살아나는 원격 개발 노드로 만들었다.**

재부팅하든, 배터리 나가서 꺼졌다 켜지든, 사람이 폰을 만지지 않아도
15초~10분 안에 SSH·ADB가 자동으로 복구된다. 루팅 안 했다.
삼성페이, 은행앱, 관공서앱 전부 그대로 살아있다.

---

## 2. 왜 이게 어려운 문제였나

안드로이드 11부터 폰끼리·PC와 무선으로 붙으려면 **무선 디버깅**을 켜야 한다.
그런데 이게 **재부팅할 때마다 강제로 꺼진다.** 삼성이 보안상 초기화한다.

여기서 닭-달걀이 생긴다.

```
원격 접속을 켜려면  →  무선 디버깅이 켜져 있어야 하고
무선 디버깅을 켜려면 →  화면 켜고 손가락으로 탭해야 한다
```

밖에 있으면 못 뚫는다. 그래서 커뮤니티 공식 문서도
**"비루팅은 재부팅마다 수동, 이게 정상"** 이라고 못 박아뒀다.
해결책은 대부분 "루팅해라"였다.

---

## 3. 어떻게 끊었나

**Shizuku 포크(thedjchi)의 START 인텐트**가 열쇠였다.

이 앱은 `WRITE_SECURE_SETTINGS` 권한을 가지면
**자기가 무선 디버깅을 스스로 켤 수 있다.**
사람 손가락이 하던 자리에 프로그램을 끼워넣은 것.

그리고 이 앱은 브로드캐스트 인텐트로 외부에서 호출된다.
= 부팅 스크립트가 대신 눌러줄 수 있다.

```
재부팅
  → Termux:Boot 가 00-shizuku.sh 실행
  → START 인텐트 발사 (30초 간격, 최대 20회)
  → Shizuku 가 무선 디버깅을 스스로 ON
  → Shizuku 서버 기동 (shell 권한 획득)
  → TCP 모드가 adb tcpip 5900 자동 실행
  → 어느 PC/에이전트에서든 adb connect 5900
```

**사람 개입 0회.**

## 4. 기술 스펙

| 항목 | 내용 |
|---|---|
| 대상 | Android 11+ / 비루팅 / Samsung One UI 실측 |
| 검증 기기 | Galaxy S25 Ultra, Galaxy Tab S9 |
| 핵심 앱 | Shizuku (thedjchi fork) v13.7.0 |
| 필수 권한 | `WRITE_SECURE_SETTINGS` (ADB로 1회 부여, 재부팅 생존) |
| 트리거 | Termux:Boot |
| 실행 방식 | `am broadcast` START 인텐트 + 멱등 재시도 루프 |
| 노출 포트 | adb tcpip 5900 |
| 네트워크 | Tailscale (내부망 전용, 공인 IP 노출 없음) |
| 세션 유지 | autossh + `ServerAliveInterval=30` + tmux |
| 복구 시간 | SSH 15~60초 / ADB 1~10분 (WiFi 연결 시점 의존) |

### 핵심 명령

```bash
# 1회 세팅 (PC에서, ADB 연결 상태)
adb shell pm grant moe.shizuku.privileged.api \
  android.permission.WRITE_SECURE_SETTINGS

# 부팅 스크립트 ~/.termux/boot/00-shizuku.sh
# WHY: WiFi 감지가 netlink 차단으로 불안정 -> 멱등 재시도로 대체
T=<앱 UI의 View intents 에서 확인한 토큰>
P=moe.shizuku.privileged.api
n=0
while [ $n -lt 20 ]; do
  am broadcast -a $P.START -p $P --es token $T
  sleep 30
  rish -c id 2>/dev/null | grep -q 2000 && break
  n=$((n+1))
done
```

### 설정 체크리스트

- Shizuku 포크: **TCP mode ON**, **Watchdog ON**
- 배터리 최적화 **제외**: Shizuku + Termux
- 삼성 **자동 차단(Auto Blocker) OFF**
- 토큰은 앱 UI → 설정 → 고급 → View intents 에서만 확인 가능
  (`shared_prefs` 직접 읽기는 SELinux로 차단됨)

## 5. 삽질하면서 확인한 것들

시행착오에서 나온 것들. 이거 모르면 똑같이 하루 날린다.

- **`adb tcpip`는 adbd 레벨 상태다.** Shizuku가 죽어도 5900은 계속 열려 있다.
  단, 재부팅은 못 넘는다.
- **토큰은 설치마다 다르다.** 기기 간 재사용 불가.
  앱 재설치/업데이트 시 재생성될 수 있다.
- **Termux에 `WRITE_SECURE_SETTINGS`를 줘도 `settings` 명령은 안 먹는다.**
  무선 디버깅을 켜는 주체는 Shizuku여야 한다.
- **부팅 직후 WiFi 감지는 신뢰할 수 없다.** 감지 대신 재시도가 답.
- **원본 Shizuku로는 안 된다.** START 인텐트/TCP 모드/워치독이 포크 전용 기능.
- **Magisk 루팅은 쓰지 않는다.** Play Integrity에 걸려서
  삼성/은행/관공서 앱이 죽는다. 이 구조는 그걸 피한다.
