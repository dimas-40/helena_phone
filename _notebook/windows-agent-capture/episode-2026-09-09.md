## 3. 질문 3 — WTG 복구 시스템 리버스 엔지니어링

### 3-1. WD Passport의 3역할
1. 부팅 가능한 구급차 (W: Windows To Go = 복구 지휘소)
2. 데이터 창고 (D:)
3. WSL 본거지 (D:\WSL\ext4.vhdx)

### 3-2. W: (복구 지휘소) 안의 복구 무기고
| 경로 | 역할 |
|------|------|
| W:\recover\RECOVER.sh / RECOVER.md | NVMe 진단→백업→Win11 재설치→WSL·28레포 재구축 자동화 |
| W:\recover\ds.py + embedded Python + .deepseek_key | DeepSeek AI 에이전트 (응급 시 원격 조종) |
| W:\recover\manage-wtg.sh | 부팅 순서 제어·에이전트 배포 |
| W:\agent\termux-bridge\ | 폰↔PC 브릿지 레포 + 백서/런북 |

### 3-3. Startup 자동기동 스크립트 3종
| 스크립트 | 역할 |
|----------|------|
| 01_wtg_nvme_check.bat | 매 부팅 NVMe 감지 → 정상이면 UEFI bootsequence 설정 후 Win11로 재부팅 |
| 02_wtg_setup_once.bat | 1회: SAN Policy=onlineall, Windows Update 차단, Tailscale 기동 |
| 03_parksy_agent.bat | 응급모드: DeepSeek Agent(ds.py) 실행, 없으면 Claude Code 폴백 |

### 3-4. 자동 부활 부팅 플로우
```
[0초]   전원 ON → BIOS가 WTG(WD Passport) 1순위 부팅
[30초]  WTG Win10 자동 로그인 (계정 dtslib)
[1분]   01_wtg_nvme_check.bat → 드라이브 스캔 ("OS" 볼륨 + winload.efi)
        ├─ NVMe 살아있음 → UEFI bootsequence=NVMe → 15초 후 재부팅 (자동 복귀, 약 68%)
        └─ NVMe 죽음 → wtg_nvme_fail.flag → 응급모드
[응급]  03_parksy_agent.bat → DeepSeek Agent → Tailscale(WTG IP) 등장
        → 폰에서 SSH로 원격 조종
```

### 3-5. 포맷 수준 재설치 (RECOVER.sh install)
```
diskpart clean → convert gpt → DISM Win11 이미지 적용 → bcdboot 부트로더
→ 재부팅 후 setup-wsl로 WSL + 28레포 + MCP + 5-Lane 재구축
```

## 4. 질문 4 — 구축 의도 확정 (교차복구 구조)

### 4-1. 핵심 설계 원칙 (메모리 원문)
> "OS는 자기 자신을 못 고친다. WSL↔Windows 교차 복구."
> "박씨가 PC 앞에 없어도 전원만 들어오면 원격 복구 가능한 구조 구축."

### 4-2. 원격 전원 제어 — 구분이 중요
| 질문 | 답 |
|------|-----|
| 원격으로 끄고/재부팅 | 가능 (shutdown /s, /r, bcdedit 부팅순서 변경 — 전부 스크립트화) |
| 원격으로 완전히 꺼진 PC 켜기 | 미검증 (BIOS AC Power Recovery 미설정, WoL/스마트플러그 없음) |

> 메모리 원문: "Wake on LAN 추천 → 박씨 진짜 문제는 WoL이 아닌 Windows Update 재부팅 저항성"

### 4-3. "Windows Update 강제 재부팅 = 사실상 셧다운" → 3중 방어
1. 예방 — Windows Update 차단 (레지스트리 NoAutoUpdate, wuauserv/UsoSvc disabled)
2. 생존 — BIOS AC 리커버리 + AutoAdminLogon + wsl-autostart.vbs + Tailscale 자동 연결
3. 최후 복구 — WTG (아래 4-4)

### 4-4. WTG = "윈도우까지 아예 망가졌다" 최악 가정 (확정)
- RECOVER.md 원문: "NVMe가 완전히 날아가도, WTG 혼자서 모든 걸 재구축할 수 있어야 진정한 복구 레인"
- 이동식 디스크로 내장 NVMe를 포맷 + 재설치 수준까지 자동화.

### 4-5. BIOS 건드린 것 / 못 건드린 것
| 구분 | 내용 | 상태 |
|------|------|------|
| 소프트웨어-펌웨어 | bcdedit /set {fwbootmgr} 로 UEFI 부팅순서·bootsequence 원격/자동 변경 | 스크립트화 |
| 하드웨어 펌웨어 | BIOS "AC Power Recovery" (전원 인가 시 자동 부팅) | 미설정 |
| 하드웨어 펌웨어 | WTG 부팅 실검증 | 미검증 |
