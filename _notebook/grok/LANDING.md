# 랜딩 디자인 계획 — 편집장

Boss: 랜딩만. 다른 CLI·코딩은 딴 에이전트. 마음에 들면 시킨다.

원장: `parksy-webzine/00_TRUTH/HOUSE.md`

## 취지 (이미 파싱)

웹진이 눕고, 영상이 세운다. 16타이틀은 Boss가 직접 만든다.  
캐러셀 구조 유지. 히어로 영상 유지. 아이북스/저스티노 카피 폐기.

## 랜딩이 뭔지

잡지 집의 **표지 + 가판대**. 앱이 아니다. 공장도 아니다.

```
1. 히어로 영상     = 집의 표지 (움직이는 커버)
2. 16줄 캐러셀     = 가판대 (제품 그 자체)
3. 아래는 짧게     = 눕다/세우다 한 줄. 끝.
```

## 유지

- 히어로 배경 영상
- 16카테 × 4권 가로 캐러셀
- 표지 사진 64 + PARKSY 마스트헤드 타이포
- 「너나 잡지랜덤여행」 동작 (위치만 옮김)

## 지금 깨진 곳

1. 히어로와 가판대 사이에 **명함 영상 카드**가 떠 있음. 잡지 집이 아님.
2. 히어로 카피가 영상 위를 많이 가림. 영상은 OK인데 글이 표지를 먹음.
3. 캐러셀 아래 **글래스/클라우드/탭바**가 아이북스. 가판대 다음이 앱 피처.
4. 책 아래 캡션이 두 줄로 깨짐. 표지가 이미 말함.
5. 툴바 검색·보관함 아이콘 = 앱. 집은 마스트헤드만.

## 어떻게 디자인하나

### 1. 히어로 = 표지
영상 풀블리드 유지.  
위에 `PARKSY` 한 줄 + `박씨 종합잡지사` 금줄.  
카피 「웹진을 눕히고…」는 빼거나 맨 아래 작게. 영상이 주인공.

### 2. 랜덤여행 = 표지 안의 단추
떠 있는 240px 영상 카드 제거.  
히어로 하단 작은 단추로만 「너나 잡지랜덤여행」.  
두 번째 영상은 안 씀. 히어로 영상 하나.

### 3. 바로 가판대
히어로 다음이 곧 16줄. 중간 공허 없음.  
줄 제목: `PARKSY FASHION` + 호 이름.  
벤치마크 브랜드(Vogue · GQ)는 작게 두거나 떼기 — 집은 PARKSY.

### 4. 책
표지 사진 + PARKSY 마스트헤드 유지.  
캡션 삭제. 호 이름은 표지 안에 있음.  
130px 폭, 3D 등뼈 유지.

### 5. 가판대 아래는 한 막만
아이북스 3카드·글래스·탭바 제거.  
한 줄: 눕다(웹진) → 세우다(YouTube) → 루프.  
푸터: `PARKSY · 박씨 종합잡지사`

### 6. 타입 락
마스트헤드 Bodoni. 본문 명조. 금줄 brass `#b08a4b`.  
표지와 랜딩이 같은 집.

## 시키면 하는 순서

1. 명함 카드 제거, 랜덤여행 단추를 히어로로
2. 히어로 글 줄이기 (영상 살리기)
3. 캡션·탭바·글래스 피처 제거
4. 캐러셀 → 푸터 간격만 잡지 가판대처럼
5. 데스크톱/모바일 스크린 확인 후 라이브

안 함: FACTORY·MCP·유튜브 파이프·웹툰 플레이어. 그건 딴 에이전트.
