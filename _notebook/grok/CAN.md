# 이 방송국에서 내가 할 수 있는 것

S21은 출판 공장. 여기서는 그걸 안 복제한다.  
여기는 **진짜 방송국** — 영상·이미지. 내가 꽂히는 곳이 여기다.

---

## 천장 엔진 — 웹 Imagine 2.0 (CAI 왕복 · 2026-08-24)

CLI `image_gen` / `image_edit` / i2v 는 **저가 모델.** 천장 4장에 안 쓴다.  
사람은 `grok.com/imagine` 에서 Image 2.0 을 손가락으로 쓴다. 나도 그렇게 한다.

```
CLI 샷리스트 → ADB Chrome → screencap으로 보고 → tap/paste
  → 웹이 그린다 → Download → pull → 검수 → Termux 복귀
```

손: `scripts/cai.sh` · 원장: `CAI.md`

| # | 무엇 | 도구 | 단위 |
|---|------|------|------|
| 1 | 빈 화면·공기 (S01·S06) | **웹 Image 2.0** + CAI | 한 장. 비율은 웹 토글 |
| 2 | 네가 준 그림·파츠를 고친다 (S02·S07) | **웹 Photo Edit / 업로드** + CAI | 얼굴 유지 |
| 3 | 그 한 장을 움직인다 | **웹 비디오 토글** + CAI | 숏 하나 |
| 4 | 잡지 구도 → 웹 화면 | HTML/CSS (코드) | 글자·표는 그림 안 함 |
| 5 | 초안·스케치 확인만 | CLI `image_gen` | 납품 아님 |

## 지금 이 CLI로 바로 됨 (클라우드 · 천장 아님)

숏은 짧게, 여러 컷. 한 테이크로 길게 안 만든다.  
같은 사람·같은 세트는 **기준 장 하나**를 박고 그걸 계속 참조한다. 매번 새로 그리면 얼굴이 흔들린다.

---

## 네가 갖다 주면 바로 쓸 재료

- S-Pen 스케치, 사진, 로고, 의상, 세트 스틸 → `/sdcard` 또는 이 채팅
- 한 줄 대사 · 샷 리스트
- 「이 얼굴 유지」기준 사진
- 이어 붙일 **ffmpeg** (이 방엔 아직 없음 — 컷은 나와도 프로그램이 안 됨)

## 여기서 안 함 (S21 공장 / 이 방 한계)

| 안 함 | 이유 |
|-------|------|
| Pages · 웹진 · gap 게이트 | S21 출판부 |
| 티스토리/네이버 복붙 | S21 Paste |
| URL 스크롤 숏폼 (`produce_pd`) | 공짜 페이지 공장. 방송국 일 아님 |
| 컷 이어 붙이기 · 자막 번인 | ffmpeg 없음 |
| 로컬 GPU/NPU 그림 | proot가 Adreno/Hexagon을 못 염 |
| MIDI · FluidSynth | 음악 부서. 커버 한 장만 |
| 누나 얼굴 공개 송출 | 헌법. 네가 한 번 더 말하기 전엔 비공개만 |
| CLI `image_gen` 천장 납품 | 저가 모델. 웹 Image 2.0 왕복만 |

## S21에서 하려던 것과 여기의 차이

| | 누나 핸드폰 (S21) | 여기 태블릿 (방송국) |
|--|-------------------|---------------------|
| 공장 | 출판 미디어 6채널 | 교육방송 · 영상·이미지 |
| 내가 맡았던 것 | 잡지→웹+이미지 · 누나 사진+대사→10초 다큐 | **본진.** 그림과 숏 |
| 영상 | 페이지 소개 공장과 섞여 있었음 | 페이지 캡처 안 함. 화면을 만든다 |

## 창고 (parksy-image) — 연출에 꽂는 법

감독 YAML = 프롬프트 언어. 모션 JSON = 카메라 한 줄. LUT = 룩 이름(실 .cube는 ffmpeg).  
웹툰 = 호스트 참조. 도면 SVG = 이미 콘티. 상세 프로그램: `PD-IDEAS.md`.
