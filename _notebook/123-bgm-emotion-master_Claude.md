## 0. 이 마스터의 용도 — 곡 목록이 아니라 **레시피**

영상에 감정이 필요할 때 편집자가 던지는 말은 **"슬픈 거"** 다. 그때 필요한 건 곡 이름이 아니라
**"그 감정을 만드는 문법"** 이다. 그래야 (a) PD 곡 중에 고르고 (b) 없으면 **직접 만들 수 있다.**

그래서 이 문서가 쓰는 **40칸 전부**에 **클리셰 문법**을 붙였다 (기본 24 + 1·2차 dyad 16):

```
조성 · 템포(BPM) · 왼손 패턴 · 선율 방향 · 화성 · 다이내믹 · 페달
```

**클리셰 = 나쁜 게 아니다.** BGM은 원래 클리셰여야 한다. 시선을 안 끌고 감정만 실어야 하니까.
"뻔하다"가 이 장르의 **요구사항**이다.

### 칸의 구조 — **40은 내가 자른 수다, Plutchik의 수가 아니다**

```
Plutchik 기본 8 × 강도 3단   = 24 기본칸   (§1)
1차 dyad (이웃 두 감정)       =  8          (§2)
2차 dyad (하나 건너 두 감정)  =  8          (§3)
3차 dyad (두 칸 건너)         =  8   ← ✂️ 여기서 잘랐다 (§3.5)
─────────────────────────────────────────
정본 전부                     = 48
이 문서가 실제로 쓴 것        = 40
```

**정정 (2026-10-06, Boss 지적):** 앞 판에 "합 40칸"이라고만 적었다. Boss가
"총 클로치크 감정 40개라고 했냐?"라고 물었고 — **아니다.** 40은 **BGM 실용 컷**이지
Plutchik의 총수가 아니다. 정본은:

| | 수 |
|---|---|
| 기본 8 × 강도 3단 | **24** |
| 모든 dyad (8 + 8 + 8) | **24** |
| **합** | **48** |
| 그중 4칸 떨어진 짝 = 반대축 | 4쌍 (§4) — dyad가 아니라 **대립** |

8개 중 둘을 고르는 경우의 수 28 = dyad 24 + 반대축 4. 빠짐없이 맞는다.

**왜 3차 dyad 8칸을 뺐나:** 두 칸 건너 조합은 BGM에서 2차 dyad와 **구분이 안 된다**
(들리는 결과가 비슷하고, 편집자가 "그 느낌"이라고 말할 때 실제로 가리키는 자리가 아니다).
그래서 42곡 레인에서는 안 쓴다. **다만 목록에서 지운 게 아니라 §3.5에 남겨뒀다** —
나중에 필요하면 그 자리에서 레시피를 쓰면 된다.

⚠️ **PD 판정은 §6 안전등급을 볼 것.** 여기 적은 사망연도는 내 기억이다 — 업로드 전 재확인 필수.

## 4. 반대축 4 — 감정은 **충돌**할 때 쓰인다

Plutchik 수레바퀴의 마주보는 칸은 **양립 불가**다. BGM에선 이게 **전환 장치**가 된다.
한 곡 안에서 축을 넘으면 "감정이 뒤집히는" 순간이 만들어진다.

| 축 | 충돌 | 영상 용도 |
|---|---|---|
| 기쁨 ↔ 슬픔 | 장조→단조 | 웃다가 무너지는 장면 |
| 신뢰 ↔ 혐오 | 온음정→불협 | 믿었는데 배신 |
| 공포 ↔ 분노 | 떨림→폭발 | 위협당하다 반격 |
| 놀람 ↔ 기대 | 급변→지속 | 예고 없던 사건 |

**실전 예:** 《월광》 1악장(슬픔) → 3악장(분노) 이 자체로 축 이동이다.
Beethoven 이 200년 전에 이미 같은 트릭을 썼다.
