## 2. 공장 토폴로지 — 태블릿은 "옵션"

| 공장(로케이션) | 워크센터 | 방식 |
|---|---|---|
| 우리 공장 (PC+Claude) | 2개 (S25 Ultra + WSL/저가 PC) | 중앙 공급 · 임대 가능 |
| **태블릿 공장** | **옵션** | **필요시 우리 WSL 임대** |
| 누나폰 공장 (S21) | 자체 (proot-Ubuntu 2) | 독립 리걸 엔터티 · 자급 · 임대 불가 |

→ **태블릿은 자체 워크센터가 필수가 아니다.** 우리 WSL을 빌려 쓸 수 있다.

## 5. 검증 원장 (28레포 × 멀티디바이스 = 2D 매트릭스)

- 28레포 5-Tier = **생산 라인(순서)**, 멀티디바이스 = **공장(로케이션)**.
- 각 칸 = "이 레포가 이 워크센터에서 **실제로 구동되는가**" 의 실측 기록.
- **계획이 아니라 검증 원장.** 중요한 건 레포 숫자가 아니라 **검증된 칸의 수**.
- 한 공장에서 검증된 레포 패턴 = 다음 공장의 **스캐폴드**로 재사용.
- 루프: ①미러(실측→뇌) → ②자식 → ③재수정(랩) → ④검증 → ⑤선물(완결만→워크센터) → ⑥기록.
