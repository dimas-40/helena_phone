# ADB 숙제 — 2026-08-21 하루 삽질 총결산 (오픈 이슈)

> 상태: **OPEN** — 마지막 1회 인증만 남음
> 결론: SPAKE2 페어링은 WireGuard/Tailscale 위에서 불가 (문서+실측 확정). 정답은 **같은 LAN에서 1회 인증 → `adb tcpip 5555`** → 키 영구 저장 → Tailscale로 어디서든 통제.

---

## 1. 문제

S25 Ultra (SM-S938N, Android 15/One UI 7) ↔ WSL/Win PC **무선 ADB 영구 링크** 구축.
USB 없이, 재부팅에 강하게.

## 2. 오늘 실측 이력 (2026-08-21, 전부 직접 확인)

| 시도 | 결과 |
|---|---|
| WSL adb pair (다이렉트) | ❌ `protocol fault (couldn't read status message)` |
| Windows adb.exe pair | ❌ 동일 protocol fault |
| 폰 Termux adb → 자기 localhost pair | ❌ 동일 protocol fault (네트워크 문제 아님 증명) |
| 역방향 SSH 터널 경유 pair | ❌ 동일 — 페어링 서버 자체가 broken |
| 폰 adb → `127.0.0.1:5555` | ❌ `emulator-5554` = 5555는 adb 포트 아님 |
| `adb connect :39611/:40643` (상시 열린 포트) | ❌ offline — Samsung 서비스지 adb 아님 |
| `service.adb.tls.port` getprop | ❌ **Access denied** (삼성이 읽기 차단) |
| `svc usb setFunctions adb` | ❌ 삼성이 조용히 무시 |
| `pm grant WRITE_SECURE_SETTINGS` | ❌ shell 권한 없음 |
| Auto Blocker OFF 후 재시도 | ❌ 여전히 protocol fault (원인은 adbd stopped였음) |

## 3. 근본 원인 (재파싱으로 확정)

**2026-03-26/27 삽질 로그와 100% 동일:**
- **SPAKE2+ 페어링 프로토콜이 WireGuard/Tailscale NAT 환경에서 일관되게 실패** (직접/터널/localhost 무관)
- Termux adb는 Android 15 wireless pairing 미지원
- 이건 버그가 아니라 **Android 15의 보안 설계** (물리 인증 강제)

**우리가 부딪힌 부수 원인들:**
- `service.adb.tls.port` 삼성 차단 → 부팅 스크립트(`adb_restore.sh`) 자동복구 체인 항상 실패
- USB 디버깅이 재부팅/보안 타이머로 자동 꺼짐 → adbd 안 뜸
- 5555 포트는 emulator/다른 서비스 (헛다리)

## 4. 해결책 (검증된 유일한 무USB 경로)

**같은 LAN에서 1회 인증** (6/16 성공 방식 = WireGuard가 아니라 LAN에서 페어링):

```
1. 폰을 PC와 같은 WiFi(네트워크)로 연결
2. Windows adb.exe:
   adb pair <LAN_IP>:<PAIR_PORT>   # LAN 경유 → SPAKE2 성공
   adb connect <LAN_IP>:<DEBUG_PORT>
   adb tcpip 5555                   # ← 페어링 의존 종료, RSA 인증으로 이주
3. 키가 /data/misc/adb/adb_keys에 영구 저장
4. 이후 Tailscale 경유: adb connect 100.103.250.45:5555 (어디서든)
```

**USB 1회도 동일한 결과** (03-26/27 문서 확정 경로):
```
USB 연결 → adb tcpip 5555 → 무선 연결
```

## 5. 오늘 이미 수리한 것 (배포 완료)

| 파일 | 수정 |
|---|---|
| 폰 `~/.termux/boot/adb_restore.sh` | v2 — 삼성 차단 프로퍼티 안 읽음, adbd 신호만 |
| WSL `~/.local/bin/adb-connect.sh` (cron 1분) | v2 — adbd 신호 → nmap 포트 발견 → 자동 연결 |
| 폰 `~/.termux/boot/adb-auto.sh` | adbd 대기 감시자 (부팅 시 자동 실행) |
| 폰 `~/adb-selfpair-termux.sh` | 자가 페어링 스크립트 |
